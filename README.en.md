# dsh-quick-reload

[![version](https://img.shields.io/badge/version-1.0.0-0969da)](https://github.com/devthires/dsh-quick-reload/releases)
[![license](https://img.shields.io/badge/license-MIT-0969da)](LICENSE)

Bind **F5** to reload the DeepSeek Harness (DSH) Web client, so newly installed
skills and plugins show up **without restarting the app**.

## The problem

When you install a skill, the files land on disk and the Host side picks them up
immediately — but the `/` slash menu keeps serving a **cached** skill catalog for
the lifetime of the page. That cache is only dropped when the agent preset
changes or the connection resets, so a freshly installed skill stays invisible
until the whole desktop app is restarted.

DSH Desktop also ships no reload shortcut of its own: the shell binds no reload
accelerator (only <kbd>F12</kbd> for DevTools), and a browser-style refresh is
not wired up. Typing `/skill-name` does not help either, because the menu
filters that stale cached list.

## What it does

Pressing <kbd>F5</kbd> reloads the renderer, which rebuilds the client and
refetches the catalog — new skills appear right away.

<img src="docs/f5.png" alt="Press F5 to reload" width="300">

Plain F5 only. Modified variants (<kbd>Ctrl</kbd>+<kbd>F5</kbd>,
<kbd>Shift</kbd>+<kbd>F5</kbd>, …) are deliberately left alone, and holding the
key down will not reload repeatedly.

## Requirements

- DSH Desktop with profile plugin support.
- Developed and tested against `dsh` 0.1.5-rc.1 with `@deepseek-ai` packages
  `0.2.0-rc.2` on Windows 11.

## Install

### DSH Desktop

Open **Settings → Plugins → Add plugin** and give the repository address:

```
https://github.com/devthires/dsh-quick-reload
```

or a local directory path when you have cloned it.

> The `dsh plugin` CLI refuses the `desktop` profile
> (`profile "desktop" is managed exclusively by the Electron application`), so
> use the settings page there.

### Custom or `web` profile

```bash
dsh plugin --profile web add github:devthires/dsh-quick-reload
```

## Usage

Press <kbd>F5</kbd> anywhere in the window.

One press after installing a skill is enough — no app restart needed.

## Uninstall

Remove the bundle from **Settings → Plugins**. The shortcut disappears with it.

## How it works

A standard DSH bundle with two halves:

| File | Role |
|---|---|
| `index.js` | Host half, a no-op (the feature is entirely client-side) |
| `client.js` | Client half, registers the F5 listener |
| `cordis.patch.yml` | Mount declaration, a single `insert` |

The client half registers its listener through `ctx.effect`, so cordis disposes
it with the plugin and no handler is left behind. The listener uses the
**capture phase**, so it works while the composer, a terminal, or a dialog input
holds focus.

> The package name, the patch row name, and the client module id must all match;
> here they are all `dsh-quick-reload`.
